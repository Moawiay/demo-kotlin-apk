# 📱 Demo Android App (Kotlin)

A modern Android demonstration application written in **Kotlin**, built and compiled automatically via **GitHub Actions CI/CD**.

## 🚀 Features
- **Pure Kotlin** implementation (`MainActivity.kt`)
- **Material 3 Design** cards & components
- Interactive Counter & Toast notifications
- Automated cloud compilation to `.apk` on every push
- Automated GitHub Releases with direct APK download

## 📦 Download APK
To download the latest compiled `.apk`:
1. Go to the [Releases](https://github.com/Moawia45/demo-kotlin-apk/releases) tab.
2. Download `app-debug.apk` directly to your phone.
